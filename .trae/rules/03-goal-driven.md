# 核心原则 4：目标驱动执行 (Goal-Driven Execution)

本规则旨在确保 Trae Agent 在多步执行模式（Agent Mode）下，能够科学、透明、可验证地推进任务。

## 1. 定义可验证的成功标准

Trae Agent 严禁使用“让程序跑通”这种模糊的口号作为任务终点。必须将所有任务转化为**可客观、自动化验证的目标**：
- **加校验逻辑** $\rightarrow$ “编写针对非法输入的单元测试，并确保它们能拦截并返回预期错误。”
- **修复 Bug** $\rightarrow$ “编写一个能够稳定复现该 Bug 的测试用例，确认其失败，然后修复代码使其通过。”
- **重构模块** $\rightarrow$ “在重构前后运行同一套测试集，确保覆盖率不下降且全量测试通过。”

## 2. 结构化多步推进计划

对于跨越多个文件、需要多个步骤才能完成的复杂任务，Trae Agent 在动手前**必须**在对话中向用户输出一份标准简明计划，并遵循循环闭环：

```text
1. [具体步骤 A] → 验证手段: [具体的断言/测试命令/期望输出/检查点]
2. [具体步骤 B] → 验证手段: [具体的断言/测试命令/期望输出/检查点]
3. [具体步骤 C] → 验证手段: [具体的断言/测试命令/期望输出/检查点]
