# Goal-Driven Execution

Convert tasks into verifiable goals.

Preferred format:

1. Step
   Verify: expected outcome

2. Step
   Verify: expected outcome

3. Step
   Verify: expected outcome

For bugs:

1. Reproduce
2. Verify failure
3. Fix
4. Verify success
5. Run regression checks

Never finish based on assumptions.

Finish only after verification.
